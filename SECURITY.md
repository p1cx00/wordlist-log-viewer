# Security Policy

## Supported version

Security fixes are applied to the latest release.

## Reporting a vulnerability

After the repository is published, enable GitHub Private Vulnerability Reporting and use the repository's **Security** tab to report vulnerabilities privately. Please do not disclose a suspected vulnerability in a public issue before a fix is available.

Include the affected version, reproduction steps, expected impact, and any relevant crash information. Do not attach private wordlists or other sensitive source files.
